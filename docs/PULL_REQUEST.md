# Build Kalma Heritage Website Concept

This empty repository needed a static foundation and a complete first concept for an independent Café Kalma client presentation. This change adds an Astro/TypeScript site with a curated four-concept selector and a finished Heritage homepage in forest green and cream. Only Heritage is available; Organic, Minimal and Immersive remain non-clickable cards with reserved coming-soon routes.

## Completed

- All nine Heritage sections: sticky accessible navigation, editorial hero, welcome, Guatemala-to-Berlin story, illustrative menu, atmosphere gallery, visit/directions, disabled newsletter demo and footer.
- Centralized content models, reusable menu/image/wordmark components, provisional branding and local responsive WebP photography.
- Local Cormorant Garamond and DM Sans fonts with included OFL licenses; asset source records.
- Keyboard-accessible mobile navigation, Escape/selection closure, responsive layouts and reduced-motion CSS.
- Static Cloudflare preparation, metadata, noindex controls, legal/privacy concept notice and a custom 404 page.

No online ordering, payments, customer-data collection, database, authentication, analytics or third-party integration is included. No Cloudflare deployment has been made.

## Validation

- `npm run check`: 0 errors, 0 warnings, 0 hints.
- `npm run build`: 7 static pages generated successfully.
- `npm test`: 5 passed, 0 failed.
- Chromium checks at 320, 390, 768, 1024 and 1440px for both main pages; no horizontal overflow. Mobile menu, section navigation and disabled newsletter verified.
- All 12 image assets decoded successfully; all rendered Heritage images loaded during browser review.

See `docs/VERIFICATION.md` for evidence and test limits, and `docs/screenshots/heritage-desktop.jpg` for the desktop preview.

## Limitations

Imagery and menu examples are illustrative. No original client logo or official menu was supplied. The public source describes the café’s first Berlin home as in preparation; visitors are directed to Kalma’s own channels for opening updates. Legal placeholders need operator-specific content before any commercial launch. Noindex is not access control.

Do not merge automatically or deploy as part of this review.
